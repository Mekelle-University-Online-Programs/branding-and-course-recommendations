\chapter{Implementation and QA Checklist}

\section{Step-by-Step Rollout}

\begin{enumerate}
  \item Complete file intake.
  \item Approve branding variables (Section 3) with leadership.
  \item Approve enhanced QA rubric (Section 7) with leadership and ID.
  \item Populate all \texttt{about/} metadata files.
  \item Remove all \texttt{[Insert ...]} placeholders.
  \item Resolve live vs. draft component conflicts.
  \item Remove embedded \texttt{<style>} blocks and inline styles.
  \item Apply common CSS to a pilot module.
  \item Run accessibility and technical QA on pilot.
  \item Fix all video captions and duplicate YouTube ID.
  \item Validate all \texttt{problem/*.xml} in Teak.
  \item Migrate \texttt{video\_iframe} to standard \texttt{video} or confirm install.
  \item Redesign \texttt{problem1.xml} self-assessment for Teak.
  \item Run full QA on the course.
  \item Export to GitHub; run GitHub Pages preview.
  \item Final sign-off in GitHub Projects.
  \item Publish.
  \item Roll out to remaining 13 courses.
\end{enumerate}

\section{Accessibility Checklist (WCAG 2.1 AA)}

\begin{itemize}
  \item[$\square$] Contrast $\geq 4.5{:}1$ normal, $3{:}1$ large
  \item[$\square$] Alt text meaningful or empty
  \item[$\square$] Captions and transcripts
  \item[$\square$] \texttt{<caption>} and \texttt{<th scope>}
  \item[$\square$] Iframes have \texttt{title}
  \item[$\square$] Keyboard-only navigation
  \item[$\square$] Focus indicators visible
  \item[$\square$] No reliance on color alone
  \item[$\square$] Logical heading hierarchy
  \item[$\square$] Language attributes set
  \item[$\square$] No autoplay, no keyboard traps
\end{itemize}
