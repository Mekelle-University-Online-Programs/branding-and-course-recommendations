\section{Template Placeholder Content — Pervasive}

Placeholder text appears in nearly every content file reviewed:

\begin{itemize}
  \item \texttt{[Insert module objective here]}
  \item \texttt{[Insert course description here]}
  \item \texttt{[Insert activity/assessment here along with dates, if applicable]}
  \item \texttt{[Insert brief module description here]}
  \item \texttt{[Insert objective with verb and learning expectation]}
  \item \texttt{[Insert email here or other contact information or erase]}
  \item \texttt{[Insert Video introduction for the module or erase if there is no video]}
  \item \texttt{[Insert banner title]}
  \item \texttt{Click "Edit" to change the title}
  \item \texttt{Add the content you want students to see on this page.}
\end{itemize}

This is the single largest content-quality issue. It maps to Roadmap
Phase 1 (Content Authoring), which is not yet complete.

\section{Invalid HTML Patterns}

Recurring structural defects:

\begin{itemize}
  \item Invalid nested lists: \texttt{<ul><ul>...</ul></ul>}
  \item Nested empty lists: \texttt{<ul><li style="list-style-type: none;"><ul>...}
  \item Empty anchors: \texttt{<span id="docs-internal-guid-...">}
  \item Orphan attributes: \texttt{<span div="" style="...">}
  \item Broken \texttt{target}: \texttt{target="[object Object]"}
  \item Heading level misuse: \texttt{<h4><img ... alt="Learning Outcomes" /></h4>}
  \item \texttt{<h2>} used inside course content, competing with platform page titles
\end{itemize}

\section{\texttt{video\_iframe} XBlock — Teak Compatibility Risk}

Two verticals use a custom \texttt{video\_iframe} XBlock pointing to
\texttt{https://media.courses.ethernet.edu.et/embed/view/...}:

\begin{itemize}
  \item \texttt{f61e7b9c527040f08f16567d874b0bde.xml}
  \item \texttt{4bfb6717391d43b8a5a569fd18378561.xml}
\end{itemize}

This XBlock is not standard in Teak. The roadmap specifies YouTube
unlisted/private as the video hosting standard. This is a
\textbf{roadmap divergence} to resolve.
