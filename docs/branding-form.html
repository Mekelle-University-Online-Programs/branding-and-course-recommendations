Section 1 — Identity

UNIVERSITY_NAME
Write the full official English name as it appears on the university charter, letterhead, and certificate. Example: Mekelle University. Do not use abbreviations here. If the official name includes "The", include it. Confirm with the Office of the President before submitting.
UNIVERSITY_NAME_SHORT
The commonly used short name or abbreviation. Example: MU. Used in banners and tight layouts where the full name will not fit. If not needed, write PENDING and give the date the decision will be made.
LOGO_URL
LOGO_URL_REVERSED
Light-on-dark version of the logo. Example: /static/mu-logo-reversed.svg. Used by the module banner which has a dark background.
FAVICON_URL
Path to the browser tab icon. Example: /static/favicon.ico. Usually set at the platform theme level, not per course. If theme-level, write theme-level, not course and give the value already configured.
FOOTER_TEXT
Exact string for the footer. Example: © 2025 Mekelle University. All rights reserved. Confirm whether the year is static or dynamic, and whether "All rights reserved" is required by policy. If the footer must include a contact email, write it on a second line.

Section 2 — Colour palette

All colours must pass WCAG 2.1 AA. The contrast checker in Part C validates automatically as you type.

PRIMARY_COLOR
6-digit hex. Example: #127DAD. Used for headings, table header backgrounds, and the module banner. Must achieve at least 4.5:1 contrast against white when used as a background (Part C row 7). If the university's primary color fails AA, provide a darker approved variant for text use.
SECONDARY_COLOR
6-digit hex. Example: #82CFF0. Used for definition callouts. Must pass 3:1 against #F5F7FA as a non-text element. If not defined, write PENDING and note that the primary color will be used.
ACCENT_COLOR
6-digit hex. Example: #F2A900. Used for keyboard focus outlines and important callouts. Must pass at least 3:1 against white and against the primary color. Choose a colour that is distinguishable from both primary and secondary. Note: #F2A900 fails the focus-outline check at 2.2:1 — choose a darker accent.
LINK_COLOR
6-digit hex. Example: #0056B3. Must pass 4.5:1 against white and against #F5F7FA. Do not use the primary color unless it passes both checks. Provide a separate value if the primary is too light for link text.
LINK_HOVER_COLOR
6-digit hex. Example: #127DAD. Colour of the link on hover or keyboard focus. Must be perceptibly different from LINK_COLOR. If no change is desired, write same as LINK_COLOR.
WARNING_COLOR
6-digit hex. Example: #b91c1c. Left border of warning callouts. Must pass 3:1 against white. Always used with an icon and label, so colour alone does not carry meaning.
SUCCESS_COLOR
6-digit hex. Example: #15803d. Must pass 3:1 against white. Same accessibility rules as the warning border.
TEXT_COLOR
6-digit hex. Example: #1f2933. Must pass 4.5:1 against white and against #F5F7FA. Avoid pure black unless required by policy.
MUTED_TEXT_COLOR
6-digit hex. Example: #52606d. Must pass 4.5:1 against white. Do not use a lighter grey; it will fail AA.
BORDER_COLOR
6-digit hex. Example: #d9e2ec. Decorative; AA contrast not required. Choose a value visible on both white and #F5F7FA.

Section 3 — Typography

FONT_FAMILY
CSS font stack. Example: "Open Sans", Arial, Helvetica, sans-serif. Always include a generic fallback. If the primary font is not a system font, attach a licence file to this form. Do not list a font without web-embedding rights.
FONT_FAMILY_HEADING
CSS font stack. Example: "Merriweather", Georgia, serif. If headings use the body font, write same as FONT_FAMILY or leave blank.
FONT_FAMILY_MONO
CSS font stack for code and file listings. Example: Menlo, Consolas, "Courier New", monospace. Usually safe to leave at the default.
FONT_LICENSE
Select one. If commercial, attach the licence PDF and note permitted page views or domains. If PENDING, give the date the licence will be confirmed.
BASE_FONT_SIZE
Example: 1rem (16px). Do not go below 1rem; smaller sizes fail WCAG 2.1 AA readability. If university policy specifies a different base, confirm it is at least 16px.

Section 4 — Header and footer

HEADER_STYLE
CSS border for content headings. Example: border-bottom: 2px solid #F2A900. Applies to headings inside course content, not the platform header. Do not use colours that fail AA as a non-text element against white.
HEADER_LOGO_POSITION
Select one. Example: left. Controls the MU logo position in the course banner block. The platform header is themed separately.
FOOTER_LOGO_POSITION
Select one. Example: right. The platform footer is themed separately.
FOOTER_LINKS
One per line, format Label | URL. Example: Privacy policy | https://www.mu.edu.et/privacy. Include only links approved for public display. Do not include social media unless policy permits. If no footer links, write none.
