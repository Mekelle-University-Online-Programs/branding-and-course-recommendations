# Findings Video Recording Guide

## Goal
Record a 12–18 minute findings video for MU+MBAD7112+DEV_01.

## Equipment
- Screen recorder: OBS Studio (free) or Loom
- Microphone: USB condenser or headset
- Backup audio: phone voice memo
- Second monitor for script

## Setup
1. Close all personal tabs, email, chat.
2. Use a clean Chrome profile logged into Studio.
3. Hide bookmarks bar (Ctrl+Shift+B).
4. Silence notifications (macOS: Do Not Disturb).
5. Set screen resolution to 1920×1080.
6. Open in tabs:
   - Studio: course outline, Module One, one HTML component
   - Text editor: `3e45c044...html`, `b824e481...html`, `81723e3f...html`, `c61ee725...html`
   - GitHub: repo `mu-mba-course-recommendations`
   - PDF: this document
7. Test recording for 30 seconds. Play back. Check audio.

## Recording Order
Follow Appendix C scenes 1–11. Do not improvise order.

## Narration Tips
- Speak slowly. Pause between scenes.
- Say the filename out loud when showing it.
- Do not read code line by line; summarize the defect.
- Do not name any individual by name.
- Do not speculate about causes; state only what is in the files.

## Sensitive Content Rules
- Do not show `policy.json` or `assets.json` in full.
- Do not show any learner data.
- Do not show `drafts/` content in detail; only show that it exists.
- Do not show login credentials or tokens.

## Post-Recording
1. Trim start/end.
2. Add chapter markers for scenes.
3. Add captions (English).
4. Upload unlisted to YouTube.
5. Add transcript as `assets/findings-transcript.srt`.
6. Add link to `README.md`.
7. Notify stakeholders per `sharing-guidance.md`.

## Distribution
- Leadership, PM, IDs, Open edX experts, QA, multimedia, ICT.
- Do not forward externally without PM approval.
