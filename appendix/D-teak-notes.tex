\section{What Teak Changes for This Project}

\begin{itemize}
  \item \textbf{Course-wide CSS} is supported via
        \texttt{course\_wide\_css} in Studio Advanced Settings.
  \item \textbf{\texttt{video\_iframe}} is not a standard XBlock.
  \item \textbf{Multiple-choice items with all correct choices}
        award a point only for the first correct choice.
  \item \textbf{Several \texttt{advanced\_modules}} in
        \texttt{DEV\_01.xml} are not shipped with Teak by default:
        \texttt{crowdsourcehinter}, \texttt{recommender}, \texttt{rate},
        \texttt{staff\_graded}, \texttt{google\_drive}, \texttt{videoalpha},
        \texttt{video\_iframe}. Confirm install status.
  \item \textbf{OLX} remains the import/export format.
  \item \textbf{Studio preview} in Teak respects course-wide CSS.
\end{itemize}
